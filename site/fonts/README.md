# `site/fonts/`

The two faces the pages use, carried here so that reading them asks nothing
of a third party. Fetched from Google Fonts on 7 September 2026, the `latin`
subset only --- every character these pages use is in it.

| file | face | |
|---|---|---|
| `archivo.woff2` | Archivo | one variable file, weights 400 to 600 |
| `ibm-plex-mono-400.woff2` | IBM Plex Mono | regular |
| `ibm-plex-mono-500.woff2` | IBM Plex Mono | medium |
| `ibm-plex-mono-600.woff2` | IBM Plex Mono | semibold |
